# Fiction Writing & Literary Editing — Skill

**Version:** 1.1.2 · Experimental

This is the portable skill component for multilingual fiction writing and literary editing.

- SKILL.md — English core instructions; work in the author's requested language.
- International literary traditions — Japanese, Russian, French, Chinese and other comparative research.
- Evaluation plan — current test design and validation status.

## Intended uses

Novel and short-story development, character and relationship design, narrative analysis, historical research, developmental and structural editing, line/style editing, and revision.

## Installation

The repository root contains plugin.json and this skill at the portable path skills/fiction-writing-literary-editing/SKILL.md. For compatible Agent Plugin importers, use the repository ZIP or the separately distributed plugin archive. Check the target host's current import flow.

**Validation status:** One exploratory self-evaluated exercise is documented. Independent blinded validation remains pending.

**Scope:** This Skill is not tied to one national literature, one genre, or one manuscript. It must not embed any author's private project as a universal rule.
