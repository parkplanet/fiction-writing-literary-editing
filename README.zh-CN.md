# 小说创作与文学编辑 · Fiction Writing & Literary Editing

[English](README.md) · [简体中文](README.zh-CN.md)

**面向全球小说创作者的多语言、跨文化 AI 创作与文学编辑 Skill。**

> 版本：1.1.2 · 实验版 · 英文核心指令 · 支持作者指定的创作语言

这不是一套只适用于中国小说的写作工具，也不是把欧美编剧理论套在所有作品上的模板。

它面向长篇小说、短篇小说、历史小说、类型小说和文学研究，帮助创作者开展故事构思、人物塑造、叙事分析、历史考据、文本诊断与修改。

研究框架重点参考**日本、俄罗斯、法国、中国及其他世界文学传统**。核心目标不是模仿某位名家，而是理解具体作品使用了什么方法、这些方法解决了什么问题、有什么局限，以及是否适合当前作品。

## 安装

使用开源 [Skills CLI](https://www.skills.sh/docs/cli) 安装。**需要 Node.js 22.20 或更新版本。**

**快速安装（交互式）：**

```bash
npx skills add parkplanet/fiction-writing-literary-editing
```

运行后，按照提示选择本 Skill 和要安装到的 AI Agent。

**安装到 Claude Code：**

```bash
npx skills add parkplanet/fiction-writing-literary-editing --skill fiction-writing-literary-editing -a claude-code -y
```

**安装到 Codex：**

```bash
npx skills add parkplanet/fiction-writing-literary-editing --skill fiction-writing-literary-editing -a codex -y
```

在项目目录中运行，默认安装到当前项目。添加 `-g` 可以进行全局安装。其他 Agent 和参数请查看 [Skills CLI 官方文档](https://www.skills.sh/docs/cli)。

**关于安装统计：** Skills CLI 默认会收集匿名安装遥测数据，用于 skills.sh 排行榜统计。用户可以通过设置环境变量 `DISABLE_TELEMETRY=1` 选择退出。

## 60 秒快速体验

安装后，把下面这段小说交给 AI Agent 试一试：

> **作者目标：** 现实主义家庭小说，结尾保留悬念，不直接解决矛盾。
>
> **小说片段：** “印刷机已经停了三个星期。米拉提出卖掉机器，哥哥却说，这是他们还清银行欠款的唯一指望。母亲把房契放在桌上：‘我能替你们再撑六个月。’米拉知道，那是父亲如今唯一住得起的地方。门外，一个顾客敲了敲已经上锁的店门。”
>
> **任务：** 请作为发展性文学编辑，最多指出两个真正重要的问题（如果存在）。区分原文事实与推断，分析每个家庭成员各自的利益，并提出不同修改方案及其代价。不编造价格或人物往事，不强迫作者把开放结局写成圆满结局。

值得观察的是：AI 能否看出经济利益与家庭责任的冲突，区分留白和漏洞，并尊重作者的艺术选择。这是**演示提示词，不代表已经得到量化测评结果**。正式评估设计见[公开校准测试](tests/calibration-v01.md)与[测试计划](tests/README.md)。

## 能做什么

- **小说构思与结构：** 主题、故事前提、长篇架构、时间线、因果链、支线和转折。
- **人物塑造：** 欲望、恐惧、自我欺骗、利益冲突、亲密关系、人物能动性及行为后果。
- **叙事分析：** 叙述视角、聚焦、叙述者可靠性、叙事时间、记忆、留白、对白和信息揭示。
- **历史与文化研究：** 制度、经济、家庭结构、物质生活、语言习惯及史实不确定性。
- **专业文学编辑：** 发展性编辑、结构编辑、语言风格编辑、连续性检查和文字校对。
- **实际创作：** 构思、场景、章节、对白和正文写作，遵循作者指定的语言与风格。
- **文学理论研究：** 比较经典作品和理论，保留不同学派的分歧，检验反例，不机械模仿。

## 跨文化文学研究框架

| 文学传统 | 代表作家与理论家 | 重点研究问题 |
|---|---|---|
| 日本 | 紫式部、夏目漱石、芥川龙之介、谷崎润一郎、川端康成 | 关系时间、迟来的告白、多重证词、社会细节、沉默，以及情节驱动的时代小说 |
| 俄罗斯 | 托尔斯泰、陀思妥耶夫斯基、契诃夫、巴赫金、什克洛夫斯基、普罗普 | 社会群像、多声部叙事、开放结局、陌生化和结构理论的适用边界 |
| 法国 | 福楼拜、巴尔扎克、普鲁斯特、加缪、杜拉斯、热奈特、巴特、托多罗夫 | 自由间接引语、社会因果、记忆、叙事时间、视角与反讽 |
| 中国及其他 | 《红楼梦》、鲁迅、张爱玲、沈从文、萧红，以及世界其他文学传统 | 家族与社会系统、历史质感、语言层次、类型和文化语境 |

详细研究问题、理论边界、资料链接见：[国际文学传统研究地图](skills/fiction-writing-literary-editing/references/international-literary-traditions.md)。

## 使用方法

你可以用中文、英文、日文、法文、俄文或其他语言与 Skill 协作。核心指令使用英文是为了便于跨平台分发；实际写作和编辑应遵循作者指定的语言，不应把中文作品自动改写成英语思维，也不应把其他语言作品统一成某种标准文风。

示例：

- “帮我检查这部长篇小说的因果链，指出人物选择是否有充分铺垫。”
- “只分析这一场戏，不要重写。区分文本事实、推断和审美判断。”
- “比较几种文学传统处理这个叙事问题的方法，同时指出每种方法的局限。”
- “润色这段中文对白，但保留人物各自的口语习惯和语气。”
- “核查历史背景，将结论标记为已证实、依赖具体语境、有争议或未知。”

## 编辑原则

1. **理论是工具，不是法律。** 不强制三幕结构、英雄之旅、每场必须冲突或人物必须成长。
2. **先看文本，再套理论。** 重要批评必须有原文、项目约束或可靠资料依据。
3. **人物不是情节机器。** 人物可以骄傲、妥协、犯错、自相矛盾，也可以不发生传统意义上的成长。
4. **模糊不等于错误。** 不可靠叙述、开放结局、沉默、非线性时间和道德悬而未决都可能是艺术选择。
5. **拒绝文化刻板印象。** 不把某个国家的文学简化成一种风格。
6. **不伪造学术依据。** 不假装读过整本书，不编造引文、史实或来源。
7. **作者保留最终决定权。** 编辑应给出诚实判断、替代方案和修改代价，不能擅自把建议写成作品设定。
